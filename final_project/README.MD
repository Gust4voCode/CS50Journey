#### Description: TODO LIST USING FLASK, BOOTSTRAP, JAVASCRIPT, it's a simple but robust CRUD project that I could apply my skills that I learned from cs50x,The To-Do List Application is a web-based platform designed to streamline task management and help users stay organized. Developed as a final project, it showcases a combination of clean design, robust functionality, and user-focused features. The application provides users with the tools they need to efficiently manage their daily tasks, ensuring that their productivity remains at its peak. Built using Flask as the backend framework, with a SQLite3 database for persistent data storage, the application emphasizes both simplicity and reliability. The frontend leverages HTML, CSS (styled with Bootstrap), and JavaScript to create an intuitive and responsive interface that adapts seamlessly across devices.The primary goal of the application is to allow users to maintain an organized workflow by creating, updating, completing, and deleting tasks as needed. Every action within the application is designed to be user-friendly and efficient, ensuring that users can focus on their work rather than struggling with complex interfaces. Tasks are stored securely within individual accounts, accessible only after logging in with a username and password. This security-focused design ensures that each user’s data remains private and protected.A notable feature of the To-Do List is its task history functionality. Whenever a task is completed or deleted, it is automatically recorded in the history section. This allows users to keep track of their progress over time and revisit completed tasks if necessary. The history serves as a reflective tool, enabling users to review their accomplishments and better understand their workflow patterns. By presenting this data clearly, the application empowers users to identify productivity trends and adjust their habits accordingly.The application’s interface is designed with simplicity in mind. It is divided into three main sections: "Tasks," where users can view and manage their active tasks; "History," which displays a log of all completed or removed tasks; and "Logout," to end the session securely. This straightforward design ensures that even users with minimal technical knowledge can navigate and use the application effortlessly.By combining essential features with a streamlined user experience, the To-Do List Application addresses the everyday organizational challenges faced by its users. Its lightweight yet powerful architecture demonstrates the potential of combining Flask and SQLite3 for backend development while maintaining a polished and functional frontend. This project not only serves as a valuable tool for personal productivity but also highlights the developer’s ability to create practical and impactful software solutions.
